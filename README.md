\# Timming — Sistema de Gestión de Eventos



Aplicación web para gestión de eventos, cronograma, control de invitados y escaneo QR.



\## Tecnologías

\- \*\*Firebase\*\* — Autenticación y Base de Datos en tiempo real

\- \*\*Vanilla JS\*\* — Interfaz sin frameworks

\- \*\*SheetJS (xlsx)\*\* — Importación/Exportación Excel

\- \*\*jsQR\*\* — Escaneo de códigos QR



\## Configuración

El archivo `index.html` ya viene configurado con los datos del proyecto Firebase:

\- Project ID: `timming-fad72`

\- Auth: Correo electrónico + Anónima activados



\## Uso

1\. Entrar como \*\*Dueño\*\* con correo y contraseña

2\. Crear evento con nombre y fecha

3\. Administrar cronograma, invitados y accesos

4\. Compartir códigos por WhatsApp



\## Despliegue

Abrir `index.html` en navegador o subir a hosting.
